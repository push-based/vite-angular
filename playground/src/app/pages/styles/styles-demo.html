Each box below is the same template with its own external stylesheet, read by ngp through styleUrl. Only the encapsulation mode differs. Two things to watch: the wavy underline, which comes from the unscoped component, and the pill behind .leaky, which comes from the app's global stylesheet.
Emulated None ShadowDom

Three modes, one template

Emulated
The default. Angular adds _ngcontent-* attributes and rewrites selectors to match them, so the styles stay in the component. Global rules from None still get in.
None
The stylesheet goes to <head> unchanged. Its .leaky rule underlines every .leaky on the page: the Emulated box, this page's own paragraph below, and even the ShadowDom box.
ShadowDom
A real shadow root, and the global stylesheet stays out: .leaky has no pill here. The underline still gets in, because Angular copies the styles of the app's other components into every shadow root it creates. CSS custom properties inherit as usual, which is why the theme colors work here too.

This paragraph belongs to the page itself, and it has class .leaky too.
