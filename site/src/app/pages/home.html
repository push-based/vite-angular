Vite plugin · Angular 22 · ngp

Angular on Vite, one module at a time

vite-plugin-ngp compiles each Angular file when Vite asks for it, with ngp, the Rust-and-TypeScript preprocessor the Angular team merged in October 2026. Vite owns the module graph. Nothing compiles the whole program before the first module is served.

Get started How it works
A prototype on a prototype. ngp isn't on npm yet, so you build it from Angular's source first, and every Angular package is pinned to 22.3.0-next.2. Use it to try per-module Angular compilation, not to ship production apps. What works today.

Setup

One plugin in your Vite config

Point the plugin at your ngp build, keep your usual index.html and main.ts, and run vite. The same transform runs in production builds and in server rendering: this site is an Angular app compiled by the plugin and prerendered with Angular SSR.
